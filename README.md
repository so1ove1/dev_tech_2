# Назначение приложения

Сервис на Go, который считает, сколько дней осталось до 1 января следующего года. 
Доступен как HTTP API, логика расчёта покрыта тестами и вынесена в отдельный пакет, не зависящий от HTTP.

## Требования для запуска

- Go 1.27.1 или новее

## Сборка

```
go build ./...
```

## Запуск

```
go run ./server
```

Сервер поднимается на порту `8080`.

## Тесты

```
go test ./...
```

Для подробного вывода:

```
go test -v ./...
```

В проекте два уровня тестов:
- юнит-тесты функции `DaysUntilNewYear` (`daysfornewyear/daysfornewyear_test.go`) — покрывают начало и конец года, високосный год, дни вокруг 29 февраля;
- интеграционные тесты HTTP-хендлера (`server/main_test.go`) — запросы через `httptest`, с проверкой статус-кода и тела ответа.

## HTTP API

### `GET /days-for-new-year`

Возвращает количество дней от заданной даты до 1 января следующего года.

**Параметры запроса**

| Параметр | Обязательный | Формат | Описание |
|---|---|---|---|
| `date` | нет | `ГГГГ-ММ-ДД` | Дата, от которой считать. Если не передана — берётся текущая дата. |

**Примеры запросов:**

```
GET /days-for-new-year
GET /days-for-new-year?date=2026-03-01
```

**Успешный ответ — `200 OK`:**

```json
{
  "days-for-new-year": 306
}
```

**Некорректная дата — `400 Bad Request`:**

Если значение `date` не соответствует формату `ГГГГ-ММ-ДД`:

```json
{
  "error": "Некорректный формат даты, ожидается ГГГГ-ММ-ДД"
}
```
